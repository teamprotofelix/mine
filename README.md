# MINE QUEST: 지뢰의 전설 — 오프라인 아케이드 지뢰찾기

Windows 지뢰찾기의 논리적 규칙을 유지하면서 콤보 전투·보스 패턴·탐험 스킬·스테이지 진행을 더한 **순수 HTML/CSS/JavaScript 게임**입니다.

## 바로 실행하기

1. ZIP을 **전체 압축 해제**합니다. `assets` 폴더와 `index.html`은 같은 위치의 하위 구조를 유지해야 합니다.
2. `index.html`을 **더블클릭**하면 Chrome, Edge 등의 브라우저에서 시작됩니다. 또는 Windows에서 `START_GAME.bat`을 실행합니다.
3. CDN, Google Fonts, npm 설치, 인터넷, API 키, 웹서버, 로그인은 **전혀 필요하지 않습니다**.
4. GitHub Pages 또는 다른 정적 호스팅에 이 폴더 내용을 그대로 게시해도 됩니다.

## 게임 모드

| 모드 | 내용 |
| --- | --- |
| 모험 / 보스전 | 숲 → 사막 → 화산 → 빙하 → 고대 유적의 5개 지역. 점차 커지는 지뢰판, 보스 HP, 공격 패턴 |
| 보스 러시 | 선택한 지역의 지뢰와 보스 체력, 공격 속도가 강화되는 상급 도전 |
| 클래식 지뢰찾기 | 초급 9×9/10개 · 중급 16×16/40개 · 고급 30×16/99개. 1회 지뢰 폭발 시 종료, 보스/스킬 없음 |

### 핵심 규칙

- 칸을 열면 인접한 **8개 칸에 있는 지뢰 개수**가 표시됩니다.
- 주변 지뢰가 0개인 칸은 인접한 안전 칸이 자동으로 펼쳐집니다.
- **첫 번째 탐색 칸과 주변 칸은 안전**하도록 지뢰를 그 뒤에 배치합니다.
- 지뢰를 모두 표시할 필요는 없습니다. **안전한 모든 칸을 열면 클리어**합니다.
- 이미 열린 숫자 칸을 다시 열었을 때 주변 깃발 개수가 숫자와 같으면 깃발을 제외한 이웃을 연속 탐색합니다. 잘못된 깃발이 있으면 폭발할 수 있습니다.
- 보스전에서는 안전 칸 공개, 정확한 깃발 설치, 연속 콤보로 보스에게 피해를 줍니다. 모든 안전 칸을 발견하면 마지막 일격으로 전투가 마무리됩니다.

### 스킬과 보스 패턴

- **정밀 탐지 (3⚡)**: 안전한 숨은 칸 한 곳을 9초 동안 표시합니다.
- **에너지 방패 (4⚡)**: 다음 지뢰 또는 보스 공격 피해를 1회 차단합니다. 최대 3회 비축.
- **자동 지뢰 해제 (5⚡)**: 숨은 지뢰 한 곳에 정확히 깃발을 표시합니다.
- **시간 왜곡 (6⚡)**: 보스 공격을 10초 지연합니다.
- 보스가 예고한 **붉은 칸은 안전한 칸**입니다. 예고 시간 안에 열면 공격이 취소되고 보너스가 지급됩니다.
- 보스를 격파하면 공격이 중지됩니다. 보스전의 체력은 4개이며 클래식은 1개입니다.
- 연속 2.5초 이내 탐색은 콤보를 이어갑니다. 정확한 깃발을 반복 회수·재설치해도 보상은 다시 지급되지 않습니다.

## 포함 파일

- `index.html` — 게임 화면
- `style.css` — 반응형 고대 판타지 UI, 스프라이트 연출, 애니메이션
- `engine.js` — 지뢰 생성/숫자/재귀 없는 BFS 펼치기/연속 열기/깃발/승리 판정
- `game.js` — 게임 상태, 보스 공격, 에너지 스킬, 효과음(Web Audio API), 기록 저장, UI 및 입력
- `assets/*.webp` — 제작된 배경·보스·용사·스테이지 이미지·아이콘 (**이미지는 모두 WebP**)
- `screenshots/*.webp` — 화면 예시
- `tests/test_engine.cjs` — 외부 패키지 없는 Node.js 규칙 엔진 테스트 (선택)
- `tests/test_browser.py` — Playwright UI 테스트 (개발용, 선택)

## 데이터 및 보안

- 플레이 중 **외부 HTTP 요청, 추적, 광고, 로그인, 외부 폰트가 없습니다**.
- 스테이지 해금과 최고 기록, 음향 설정은 `localStorage`에만 저장을 시도합니다. 브라우저 설정이나 `file://` 로컬 저장소 제한에 따라 새로고침 이후 보존되지 않을 수 있습니다.
- 게임 내 효과음은 음악 파일 다운로드 대신 Web Audio API로 즉시 생성합니다. 음향 ON/OFF를 지원합니다.
- 브라우저 보안 설정과 운영체제에 따라 파일 직접 열기가 제한된다면 조직 내부의 **정적 웹서버**에 폴더 전체를 올려 실행하세요. 서버사이드 프로그램은 필요 없습니다.
